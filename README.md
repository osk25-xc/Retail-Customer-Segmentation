# Retail Customer Segmentation | RFM Analysis

A Python analytics project that segments customers using Recency, Frequency, and Monetary (RFM) measures to better understand purchasing behavior.

## Business Objective
Explore customer purchasing patterns and create interpretable segments that can inform further customer-retention and marketing analysis.

## RFM Framework
- **Recency:** How recently a customer purchased
- **Frequency:** How often a customer purchased
- **Monetary:** How much a customer spent

## Analysis Workflow
1. Inspect data structure and check data quality.
2. Calculate RFM measures from transaction history.
3. Create customer segments using the project's scoring or clustering approach.
4. Compare segment size and revenue contribution.
5. Visualize distributions and summarize possible business actions.

## Tools
Python · Pandas · NumPy · Matplotlib · Seaborn · Scikit-learn · Jupyter Notebook

## Repository Contents
The repository describes data files, notebooks, visualizations, and a requirements file. Refer to the actual files in the repository for the available outputs.

## Business Questions
- Which customers purchase recently and frequently?
- Which segments contribute more monetary value?
- Which customer groups may need re-engagement?
- How could segment-level messaging differ?

## Business Value
RFM analysis provides a simple, explainable way to compare customer behavior. Segment labels are analytical aids rather than fixed customer identities; any campaign should be tested and evaluated before rollout.

## How to Run
1. Clone or download the repository.
2. Install dependencies listed in `requirements.txt`.
3. Open the notebook in Jupyter and confirm dataset paths.
4. Run the notebook cells in order.
