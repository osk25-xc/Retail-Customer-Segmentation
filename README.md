\# 📊 Retail Customer Segmentation



A Python-based retail customer segmentation project that uses \*\*RFM (Recency, Frequency, Monetary) analysis\*\* to understand customer purchasing behavior and identify meaningful customer groups.



\## 🎯 Project Objective



The objective of this project is to analyze customer purchasing behavior and segment customers based on:



\* \*\*Recency\*\* — How recently a customer purchased

\* \*\*Frequency\*\* — How frequently a customer purchases

\* \*\*Monetary\*\* — How much a customer spends



The analysis provides business-oriented insights that can support customer retention, targeting, and marketing strategies.

\## 🔍 Analysis Performed



\### 1. Data Quality Analysis



\* Checked dataset dimensions

\* Inspected data types

\* Checked missing values

\* Checked duplicate records

\* Generated statistical summaries



\### 2. RFM Analysis



Customers were evaluated using three key metrics:



| Metric    | Description                             |

| --------- | --------------------------------------- |

| Recency   | Days since the customer's last purchase |

| Frequency | Number of purchases made                |

| Monetary  | Total customer spending                 |



\### 3. Customer Segmentation



Customers were assigned an RFM score and grouped into four business segments:



\* \*\*Champions\*\*

\* \*\*Loyal Customers\*\*

\* \*\*Potential Customers\*\*

\* \*\*At Risk\*\*



\### 4. Revenue Analysis



Revenue was analyzed across:



\* Customer segments

\* Product categories

\* Countries
